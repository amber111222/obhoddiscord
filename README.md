# 🛡️ Discord Bypass Pro (Zapret Edition)

Высокоскоростной инструмент для обхода блокировок Discord (текстовые чаты, голосовые каналы WebRTC, видео и стримы) на Windows 10/11 с современным широкоформатным интерфейсом **16:9**.

---

Вам **не нужно ничего собирать**! Готовая программа уже находится прямо в этом репозитории на главной странице:

### 📥 [Скачать DiscordBypass.exe (Релиз v1.0)](https://github.com/amber111222/obhoddiscord/releases/download/v1.0/DiscordBypass.exe)

1. Скачайте файл **`DiscordBypass.exe`** (кнопка выше или из раздела [Releases v1.0](https://github.com/amber111222/obhoddiscord/releases/tag/v1.0)).
2. Запустите **`DiscordBypass.exe`** (он автоматически запросит права Администратора для загрузки сетевого драйвера).
3. При запуске приложение автоматически проведет быстрый тест серверов Discord, найдет наилучший пресет под вашего провайдера и включит обход!
4. Запустите Discord и общайтесь без лагов и задержек!

## ✨ Возможности

- 🚀 **Полный обход Discord:** восстанавливает доступ к сообщениям, вложениям, голосовым комнатам (Voice RTC) и демонстрации экрана.
- 📺 **Современный 16:9 Dashboard:** широкоформатный двухколоночный интерфейс на CustomTkinter (1152×648).
- ⚡ **23 готовых пресета Zapret:** тонко настроенные стратегии десинхронизации пакетов (`ALT`, `Voice Fast`, `ALT2 Multisplit`, `ALT6`, `FAKE TLS AUTO` и др.).
- 🔍 **Умное автоопределение (Benchmark):** автоматически тестирует живые шлюзы Discord на задержку (ping) и выбирает самый быстрый пресет под вашего интернет-провайдера.
- ⏱ **Живая статистика:** таймер аптайма, мониторинг PID процесса `winws` и сетевой пинг.
- 📡 **Встроенная диагностика:** проверка доступности API, Gateway, CDN и Media/WebRTC серверов в один клик.

## 📂 Структура репозитория

```text
obhoddiscord/
├── DiscordBypass.exe    # 🚀 Готовая программа (скачай и запусти!)
├── README.md            # Документация и инструкции
├── zapret/              # Драйверы WinDivert, бинарники winws и пресеты
└── src/                 # Исходный код (для разработчиков)
    ├── app.py           # GUI интерфейс 16:9 на CustomTkinter
    ├── engine.py        # Движок управления процессом winws
    ├── autodetect.py    # Модуль бенчмарка и автоподбора пресетов
    ├── presets.py       # Загрузка и приоритизация 23 пресетов
    ├── main.py          # Точка входа
    └── build_exe.py     # Скрипт сборки PyInstaller
```

## 🛠 Для разработчиков (сборка из исходников)

Если вы хотите внести изменения в исходный код:

```bash
# Установка зависимостей
pip install customtkinter pyinstaller

# Сборка исполняемого файла
python src/build_exe.py
```
Собранный файл автоматически появится в корне проекта: `DiscordBypass.exe`.
