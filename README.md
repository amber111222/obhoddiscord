# 🛡️ Discord Bypass Pro (Zapret Edition)

Высокоскоростной инструмент для обхода блокировок Discord (текстовые чаты, голосовые каналы WebRTC, видео и стримы) на Windows 10/11 с современным графическим интерфейсом в формате 16:9.

---

## ✨ Возможности

- 🚀 **Полный обход Discord:** восстанавливает доступ к сообщениям, вложениям, голосовым комнатам (Voice RTC) и демонстрации экрана.
- 📺 **Современный 16:9 Dashboard:** широкоформатный двухколоночный интерфейс на CustomTkinter (1152×648).
- ⚡ **23 готовых пресета Zapret:** тонко настроенные стратегии десинхронизации пакетов (`ALT`, `Voice Fast`, `ALT2 Multisplit`, `ALT6`, `FAKE TLS AUTO` и др.).
- 🔍 **Умное автоопределение (Benchmark):** автоматически тестирует живые шлюзы Discord на задержку (ping) и выбирает самый быстрый пресет под вашего интернет-провайдера.
- ⏱ **Живая статистика:** таймер аптайма, мониторинг PID процесса `winws` и сетевой пинг.
- 📡 **Встроенная диагностика:** проверка доступности API, Gateway, CDN и Media/WebRTC серверов в один клик.

---

## 🛠 Требования

- Windows 10 / 11 (x64)
- Права Администратора (для загрузки сетевого драйвера WinDivert)
- Python 3.10+ (для сборки из исходников)

---

## 🚀 Быстрый старт

### Запуск готового приложения:
1. Запустите `DiscordBypass.exe` от имени **Администратора**.
2. Приложение автоматически активирует оптимальный пресет `general (ALT)`.
3. Запустите Discord и общайтесь без ограничений!

### Сборка из исходников:
```bash
pip install customtkinter pyinstaller
python build_exe.py
```
Готовый исполняемый файл будет скомпилирован в папку `dist/DiscordBypass/`.
